# صحن — مساعدي الغذائي

تطبيق ويب عربي RTL لتسجيل الوجبات ومتابعة السعرات والمغذيات.

## الملفات
- `index.html`: الواجهة، سجل الوجبات، الحسابات، IndexedDB، التعديل والحذف والبحث والتقارير.
- `manifest.webmanifest`: تعريف تطبيق PWA.
- `sw.js`: تخزين ملفات الواجهة للعمل عند انقطاع الإنترنت بعد أول تحميل ناجح. عند إصدار تحديث جديد، تتغير نسخة الكاش لتجنب بقاء واجهة قديمة.
- `icons/`: أيقونات التطبيق.
- `fonts/`: خط Tajawal (SIL Open Font License، انظر `fonts/tajawal-LICENSE.txt`).

## التصميم
متغيرات الألوان والمسافات والزوايا موجودة في `:root` داخل `index.html`، وتدعم الوضع الفاتح والداكن (حسب إعداد الجهاز أو `data-theme`). التصميم مستوحى من نظام نَسّق، والشعار العربي «صحن» مخصص للتطبيق.

## إعداد Supabase والمزامنة
- نفّذ `supabase/setup.sql` من Supabase → SQL Editor لإنشاء جدولي `meals` و`shared_schedule` وسياسات RLS التي تعزل بيانات كل حساب.
- سجّل الدخول بنفس حساب Supabase في صحن ونَسّق حتى تظهر الوجبات والجدول المشترك بين التطبيقين. يلزم تفعيل Email في إعدادات Authentication وتأكيد البريد إذا كان مطلوبًا.
- المزامنة السحابية لا يمكن اعتبارها مختبرة فعليًا إلا بعد تجربة تسجيل الدخول والإضافة والتعديل والحذف في التطبيقين على مشروع Supabase الحقيقي.

## النشر على GitHub Pages
من إعدادات المستودع: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## ملاحظات مهمة
- البيانات تُحفظ محليًا في IndexedDB على المتصفح/الجهاز. احتفظ بنسخ احتياطية منتظمة؛ مسح بيانات Safari قد يحذفها.
- أزرار إضافة/تعديل/حذف الوجبات والحسابات الأساسية والتصدير والاستيراد تعمل محليًا عند فتح الموقع في متصفح مدعوم.
- المساعد الذكي يستخدم نقطة اتصال Worker خارجية (`/ask`)؛ تحليل الصور قد يرسل صورة مصغّرة إلى تلك الخدمة. تأكد من سياسة الخصوصية وإعدادات الخدمة قبل استخدام صور حساسة.
- اختبر النسخة بعد رفعها إلى GitHub Pages قبل الاعتماد عليها يوميًا.
